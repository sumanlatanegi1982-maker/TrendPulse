Data Flow — Step by Step

1
User opens browser → Flask serves index.html → Frontend renders stream filter buttons (Gaming, Education, Tech, etc.)
2
Frontend calls /api/youtube/trending?stream=gaming → Backend checks if cached_data.json exists
3a
Cache HIT → Load videos from cached_data.json → Re-tag each video with correct stream → Return to frontend (ZERO API calls)
3b
Cache MISS → Call BrightDataClient.scrape_youtube_videos() → Trigger async scrape → Poll for completion → Download results
4
Self-Healing → Validate each record (url, title required) → Broken records re-scraped up to 3 cycles → Good records merged → Saved to cached_data.json
5
Frontend renders → Video cards with thumbnails, titles, views, likes → Analytics charts (view distribution, top 5, stream comparison)
6
Scheduled refresh → Background thread runs schedule.run_pending() every 60s → At 2:00 AM daily → Re-scrape all streams → Overwrite cache

Key Features

🎯 10 Content Streams

Gaming, Education, Tech, Music, Comedy, Fitness, Cooking, Lifestyle, News, Finance — each with 3 search keywords scraped via Bright Data.

🔄 Self-Healing Scraper

If Bright Data returns broken records (missing title, null URL), the system automatically re-scrapes just those records up to 3 times before skipping.

💰 Credit-Saving Cache

Scrape once → save to cached_data.json → reuse indefinitely with zero API calls. Set USE_CACHED_DATA=true to skip the API entirely.

⏰ Scheduled Auto-Scraping

Background scheduler runs daily at 2:00 AM — scrapes all 10 streams and replaces old data. New trends are always fresh.

📅 7-Day Recency Filter

Only videos from the last 7 days are shown — regardless of view count. This ensures you see current trends, not evergreen content.

📊 Analytics Dashboard

View distribution bar chart (6 buckets), Top 5 trending videos ranked by views, and stream comparison showing which stream has the highest average views.

🎬 Videos + Shorts Separation

Automatically parses duration and separates Shorts (≤60 seconds) from regular videos. Toggle between tabs to focus on either format.

🔧 Corrupted Cache Fix

On cache load, every video is force re-tagged with its correct stream from the cache key — fixes data corrupted by old code mutations.
